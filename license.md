## ⚙️ Quick Setup

Installing the hack is incredibly simple. It is a browser bookmarklet.

```bash

# Step 2: Name it "Nitro Hack"
# Step 3: In the URL field, paste the JavaScript code from the repository
# Step 4: Go to Nitro Type and start a race
# Step 5: Click the bookmark while on the race page
```

Once clicked, a small overlay will appear in the top-left corner of your screen. Select your desired speed and click "Start." The script will take over and type the race for you.

## 🧠 Under The Hood: The DOM Injection

How does the hack actually work? Nitro Type is a web game. The text you need to type is rendered in the HTML DOM (Document Object Model).

Our script uses `document.querySelector` to find the specific HTML elements that contain the race text and the input field. It extracts the text, stores it in a variable, and then uses a `for` loop to simulate the typing.

To simulate the keystrokes, we use the `dispatchEvent` API. We create a new `KeyboardEvent` for each character and dispatch it to the input field. This tricks the game into thinking a real human is typing. We also include a random delay between keystrokes (using `setTimeout`) to avoid triggering the game's anti-cheat detection.
